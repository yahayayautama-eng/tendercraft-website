| `tendercraft-mark.svg` / `tendercraft-mark-1024.png` | Colour mark, transparent background |
| `tendercraft-mark-white.svg` / `-black.svg` | One-colour mark for photos and print |
| `tendercraft-wordmark-on-dark.svg` / `-on-light.svg` | Mark plus "Tendercraft", with the text converted to outlines |
| `x-avatar.svg`, `x-header.svg` | Editable sources |

The images are generated by `brand.py` (kept outside the repo). The text is outlined from Geist, the font the website uses, so the files look the same on every machine.

## Logo

- **Mark:** a C whose top stroke is also the crossbar of a T, drawn with one stroke weight and rounded ends. The mint dot reads as a full stop.
- **Colours** (the same palette as the website):
  - Ultraviolet `#8B70FF` → `#6544F0`
  - Mint `#3DF2C0` (dot)
  - Ink `#07070B`
  - Paper `#F7F6F2`
- **Font:** Geist SemiBold for the wordmark and Geist Regular for supporting text.
- **Clear space:** leave at least the height of the mint dot on every side.
- **Smallest size:** 16 px for the mark and 96 px wide for the wordmark. Below 24 px, use the one-colour mark.
